Escape Systems: stage A Initial System Design

Permanent IDVR-DST-0015 stage AOwnerFramework ownerVerification statusUnverified (generic framework content, not yet content-reviewed)Last reviewed2026-10-12Design treeFull Aircraft > Mechanical Systems > Escape Systems > Stage A

Framework template for the Initial System Design stage section of the Escape Systems Sub-team page (6C.5, 6C.6), aligned with Lifecycle Stage Initial System Design. Default content, Placeholder (generic, fictional); items marked Draft are starter content to be reviewed.

Entry criteria

  • Allocated Requirements and interfacing Systems identified
  • Concept layout in the integrated model
  • Risks and design options recorded

Sign-off team Disciplines (agreement required, 6C.19)

Design Safety Airworthiness and Certification Configuration Management Quality Weight Mechanical Systems

Items of every Discipline for this stage, less items that apply only to Design Types the team does not use (4.4). Disciplines a project marks not applicable are removed in its Production Hub.
