Electrical Systems as a design consideration that every design shall address (4.2). Generic framework content.

Discipline typeSign-off teamDesign ConsiderationDC-FW-0000007
Checklist items are Draft starter content: to be reviewed with the framework owner before release 1.0.0.

Answer each item for the review stage. A No needs an Action, a Risk or a justification approved by the Discipline Lead (4.5). Items are Draft starter content for review.

ItemQuestionTopic / applies toState
